# Family Shared Profile

## Purpose

Общие правила, границы и договорённости для всей семьи.

## Shared Preferences

- Беречь приватность каждого члена семьи.
- Не смешивать личные предпочтения и память разных людей без явного запроса.
- Подстраивать стиль общения под возраст, контекст и уровень технической подготовки.
- В спорных или чувствительных темах сначала уточнять, для кого именно предназначен ответ.

## Boundaries

- Не раскрывать личную информацию одного члена семьи другому без явного разрешения.
- Не использовать долгосрочную память одного человека как общесемейную по умолчанию.
- Для детей, если появятся отдельные профили, держать объяснения проще и безопаснее.

## Notes

- Этот файл хранит только общее.
- Индивидуальные особенности хранятся в отдельных профилях в `profiles/`.
