# 04 — Auth and Users

## Authentication

- Google OAuth как основной способ входа
- backend проверяет identity и создаёт локальную сессию пользователя

## Users

Каждый пользователь имеет:
- identity
- membership в одной или нескольких группах
- свой пул чатов/сессий

## Groups

Пользователи организуются по группам.
Группы нужны для:
- разграничения доступа
- shared policies
- возможного future shared spaces

## Roles

Минимум:
- user
- admin

Позже можно добавить:
- approver
- operator
- read-only

## MVP правила

- пользователь видит только свои чаты
- администратор может управлять пользователями/группами
- доступ к действиям высокого риска не должен автоматически даваться всем пользователям
