# 00 — Overview

## Продукт

Отдельное приложение для общения с Jarwis с UX ближе к ChatGPT:
- отдельные чаты
- список сессий
- новый чат
- независимые контексты
- удобное переключение между темами

## Цель

Уйти от ограничений Telegram как основного интерфейса, сохранив:
- многосессионность
- приватность
- управляемый доступ
- пригодность для нескольких пользователей

## Основные требования

- клиент для iPhone / macOS / Android / Windows
- Chromium-based / web-first подход
- HTTPS-транспорт
- Google OAuth
- nginx в контейнере как внешний входной слой
- multi-user
- groups/roles
- у каждого пользователя свой пул чатов/сессий
- возможность передавать проект субагентам по частям

## Оценка трудоёмкости

- MVP: 100–180 человеко-часов
- usable version: 180–350 человеко-часов
- polished + security hardening: 350–600 человеко-часов
