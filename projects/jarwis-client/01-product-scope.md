# 01 — Product Scope

## In scope

- отдельное приложение для общения с Jarwis
- UX ближе к ChatGPT, чем к мессенджеру
- список чатов и создание новых сессий
- многопользовательская работа
- авторизация через Google OAuth
- группы пользователей
- управление доступом к чатам/сессиям
- серверный вход через nginx
- интеграция с существующим OpenClaw/Jarwis backend

## Out of scope (на первом этапе)

- нативный iOS/macOS/Android/Windows клиент с полностью отдельными кодовыми базами
- E2E-шифрование прикладного уровня
- идеальный full PQ-TLS production stack
- сложная billing/tenant economics система
- marketplace / plugin ecosystem внутри клиента

## Продуктовая позиция

Это не мессенджер и не админка.
Это специализированный chat client для общения с Jarwis.
