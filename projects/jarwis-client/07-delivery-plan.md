# 07 — Delivery Plan

## Phase 1 — Product skeleton

Цель: доказать, что клиент как многосессионный интерфейс вообще работает.

### Задачи
- определить frontend stack
- определить backend bridge shape
- поднять nginx container entry
- сделать Google OAuth login
- сделать create/list/open chat
- сделать send/receive messages

## Phase 2 — Usable daily workflow

Цель: сделать приложение пригодным для повседневного использования.

### Задачи
- rename/archive chats
- search basics
- mobile-friendly UX
- better error handling
- user/group admin basics
- logging and diagnostics

## Phase 3 — Security and polish

Цель: сделать систему устойчивой и безопасной.

### Задачи
- security review
- audit logs
- permission refinement
- approval flows if needed
- TLS hardening
- evaluate hybrid PQ TLS path
