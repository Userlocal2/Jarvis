# Jarwis Client Project

Цель: создать отдельное приложение для общения с Jarwis с UX ближе к ChatGPT, чем Telegram, при сохранении контроля, приватности и многосессионной модели.

## Что решили на текущем этапе

- Web UI OpenClaw не подходит как основной интерфейс; он остаётся локальной панелью управления.
- Telegram остаётся временным каналом, но не является финальным UX.
- Нужен отдельный клиент с многими чатами/сессиями.
- Клиент должен работать на iPhone, macOS, Android, Windows.
- Базовая идея клиента: Chromium-based app / web-first подход с возможностью thin wrappers.
- Транспорт: HTTPS, с прицелом на PQ/hybrid PQ TLS в будущем.
- Авторизация: Google OAuth.
- Сервер: nginx в контейнере перед backend-слоем.
- Поддержка нескольких пользователей.
- Пользователи организуются по группам.
- У каждого пользователя свой пул чатов/сессий.
- Всё должно быть разложено так, чтобы это можно было передавать субагентам на реализацию.
